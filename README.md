# ครูกระดาน (Kru Board)

ติวเตอร์ AI ส่วนตัวแบบ fullstack: ครูพูดอธิบายเป็นเสียงไปพร้อมกับเขียนทีละขั้นบนกระดาน รองรับภาษาไทยและภาษาอังกฤษ

## ฟีเจอร์

| ฟีเจอร์ | รายละเอียด |
|---|---|
| 4 โหมด | เรียนหัวข้อ · ช่วยทำการบ้าน (คำใบ้ทีละขั้น / ดูเฉลยเต็ม) · เตรียมสอบ (สรุป + ควิซ) · คุยทั่วไป |
| อัปโหลดไฟล์ | รูป (JPG, PNG, WebP, GIF), PDF, ไฟล์ข้อความ (TXT, MD, CSV) สูงสุด 10 ไฟล์ ไฟล์ละ 20 MB กดแนบ ลากวาง หรือวาง (Ctrl+V) ก็ได้ |
| กระดาน | ลายมือทีละบรรทัด สูตรคณิต กราฟ แผนภาพ ตาราง |
| พากย์เสียง | ครูพูดทุกขั้นเป็นภาษาไทยหรืออังกฤษ ทุกข้อความมีปุ่มอ่านออกเสียง เลือกเสียงและความเร็วได้ |
| พูดแทนพิมพ์ | กดไมค์แล้วพูดได้ทั้งไทย (th-TH) และอังกฤษ (en-US) |
| ภาษา | ปุ่ม ไทย / EN เปลี่ยนทั้งหน้าจอ ภาษาที่ครูสอน และเสียงพากย์ |
| ให้ครูตรวจ | เขียนวิธีทำบนกระดานเองแล้วส่งให้ครูตรวจ |
| ประวัติ | บทเรียนและไฟล์ถูกเก็บบนเซิร์ฟเวอร์ (`data/`) เปิดกลับมาเรียนต่อได้ |

## ติดตั้งและรัน

ต้องมี Node.js 20.12 ขึ้นไป (แนะนำ 22)

```bash
npm install
cp .env.example .env      # Windows: copy .env.example .env
# แก้ไฟล์ .env ใส่ ANTHROPIC_API_KEY=sk-ant-...
npm start
```

เปิด http://localhost:3000

ถ้าจะใช้จากมือถือที่ต่อ Wi‑Fi เดียวกัน ให้ตั้ง `HOST=0.0.0.0` และ `APP_PASSWORD=...` ใน `.env` แล้วเปิด `http://<IP ของคอม>:3000` แต่ไมค์จะใช้ได้เฉพาะบน `localhost` หรือ HTTPS

## เสียงพากย์

เวอร์ชันเซิร์ฟเวอร์ใช้เสียงที่มีในเครื่อง (Web Speech API) ซึ่งฟรีและไม่ต้องใช้คีย์เพิ่ม
- **Chrome / Edge:** ใช้ได้ทั้งพูดและฟัง Edge มีเสียงไทยแบบ Natural ให้เลย
- **Windows:** ถ้าไม่มีเสียงไทย ให้ติดตั้งที่ Settings › Time & language › Speech › Add voices › ไทย
- **Android / iPhone:** มีเสียงไทยในตัว
- **Firefox:** ใช้ไมค์ไม่ได้ แต่พิมพ์ได้ตามปกติ

## โครงสร้าง

```
server/index.js   Express: หน้าเว็บ, /api/upload, /api/chat (สตรีม SSE), /api/lessons, /api/files
server/claude.js  เรียก Claude API (คีย์อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น) แนบรูป/PDF/ข้อความ
server/store.js   เก็บบทเรียนและไฟล์เป็นไฟล์ใน data/ (ไม่ต้องใช้ฐานข้อมูล)
web/app.html      หน้าเว็บ
web/app.js        ตัวแอปฝั่งหน้าเว็บ (กระดาน, เสียง, อัปโหลด, ประวัติ)
web/i18n.js       ข้อความภาษาไทย/อังกฤษ
web/shared.js     คำสั่งครูและตัวอ่านคำตอบ (ใช้ร่วมกันทั้งเซิร์ฟเวอร์และหน้าเว็บ)
```

## API

| Method | Path | ใช้ทำอะไร |
|---|---|---|
| GET | `/api/health` | สถานะเซิร์ฟเวอร์ |
| POST | `/api/upload` | อัปโหลดไฟล์ (multipart, ฟิลด์ `files`) |
| POST | `/api/chat` | ส่งข้อความ ตอบกลับเป็น Server‑Sent Events: `start`, `delta`, `done`, `error` |
| GET | `/api/lessons` | รายการบทเรียน |
| GET / DELETE | `/api/lessons/:id` | เปิด / ลบบทเรียน (ลบไฟล์ที่แนบด้วย) |
| GET | `/api/files/:id` | ดาวน์โหลดไฟล์ที่อัปโหลด |

เมื่อตั้ง `APP_PASSWORD` ทุก `/api/*` ยกเว้น `/api/health` ต้องมี header `Authorization: Bearer <password>`

## เปิดใน Claude โดยไม่ต้องมีเซิร์ฟเวอร์

ไฟล์ใน `web/` เผยแพร่เป็น Artifact บน claude.ai ได้ด้วย แบบนั้นจะใช้บัญชี Claude ของผู้เปิดและเสียง Claude แต่รองรับเฉพาะรูปและไฟล์ข้อความ (ไม่รองรับ PDF)
