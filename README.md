# ครูกระดาน

ติวเตอร์ AI ส่วนตัวที่พูดอธิบายไปพร้อมกับเขียนทีละขั้นบนกระดาน สร้างขึ้นเองตั้งแต่ต้น ทุกฟีเจอร์ใช้ได้โดยไม่มีระบบเสียเงินหรือจำกัดจำนวนบทเรียน

## ฟีเจอร์

| ฟีเจอร์ | รายละเอียด |
|---|---|
| เรียนหัวข้อ | ถามเรื่องอะไรก็ได้ ครูอธิบายทีละขั้นบนกระดาน แล้วถามเช็กความเข้าใจ |
| ช่วยทำการบ้าน | พิมพ์หรือถ่ายรูปโจทย์ ครูให้คำใบ้ทีละขั้นให้คิดเอง มีปุ่ม "ขอคำใบ้" และ "ดูเฉลยเต็ม" |
| เตรียมสอบ | วางโน้ตหรือแนบรูปโน้ต ครูสรุปบนกระดานแล้วทำควิซปรนัยพร้อมเฉลย ให้คะแนน และสอนข้อที่ผิด |
| กระดาน | เขียนทีละบรรทัดแบบลายมือ มีสูตรคณิต (เศษส่วน ราก ยกกำลัง) กราฟฟังก์ชัน แผนภาพ ตาราง |
| เสียงครู | ครูพูดอธิบายในแต่ละขั้น เลือกเสียงและความเร็วได้ |
| พูดแทนพิมพ์ | กดไมค์แล้วพูดคำถามได้ |
| เขียนบนกระดานเอง | กดปากกา เขียนวิธีทำ แล้วกด "ให้ครูตรวจ" |
| ควบคุมการเล่น | เล่น/หยุด ข้ามขั้น เล่นใหม่ แสดงทั้งหมด |
| ประวัติบทเรียน | บันทึกไว้ในเบราว์เซอร์ เปิดกลับมาเรียนต่อได้ |
| ตั้งค่า | วิชา ระดับชั้น ภาษา (ไทย/อังกฤษ) ความลึกของคำตอบ |
| ธีม | สว่างเป็นไวต์บอร์ด มืดเป็นกระดานดำ ใช้ได้บนมือถือ |

## วิธีใช้

**แบบที่ 1: เปิดใน Claude (ไม่ต้องใช้ API key)**
เปิดลิงก์ Artifact ที่เผยแพร่จาก `app/kru-board.html` บน claude.ai ระบบจะถามอนุญาตครั้งแรก จากนั้นใช้บัญชี Claude ของคุณ ไม่มีค่าใช้จ่ายเพิ่มนอกจากแพ็กเกจที่มีอยู่แล้ว

**แบบที่ 2: เปิดไฟล์เองหรือโฮสต์เอง**
เปิด `index.html` ในเบราว์เซอร์ (หรือโฮสต์บน GitHub Pages) แล้วใส่ Anthropic API key ในหน้าตั้งค่า คีย์จะเก็บไว้ในเบราว์เซอร์นั้นเท่านั้น และคิดค่าใช้งานตามการใช้ API ของคุณ

## ไฟล์

- `app/kru-board.html` ไฟล์หลักของแอป (ใช้เผยแพร่เป็น Artifact)
- `index.html` ไฟล์ที่สร้างจาก `./build.sh` สำหรับเปิดตรงหรือโฮสต์
- `build.sh` ใช้สร้าง `index.html` ใหม่หลังแก้ `app/kru-board.html`
